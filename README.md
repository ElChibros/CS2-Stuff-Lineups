# 🎯 CS2 Stuff Lineups

Une application web minimaliste et **mobile-first** conçue pour garder vos repères de grenades Counter-Strike 2 (smokes, molotovs, flashbangs) à portée de main sur votre smartphone pendant vos parties.

---

### ✨ Fonctionnalités

- 📱 **Mobile-First & PWA** : Pensé pour être posé sur un support à côté de votre écran. Ajoutez-le à l'écran d'accueil de votre téléphone pour une expérience plein écran sans barre d'adresse.
- 🗺️ **Filtrage instantané** : Sélection par Map (*Mirage, Inferno, Nuke, Dust II...*), Camp (*T / CT*) et type de grenade (*Smoke, Molotov, Flash*).
- 🖱️ **Détails de lancer précis** : Type de clic (*Gauche, Droit, G+D*) et mouvement (*Statique, Jumpthrow, W+Jumpthrow, etc.*).
- 🔍 **Zoom haute résolution** : Visualisation plein écran du viseur et des pieds pour un pixel-perfect throw.
- ⚡ **Générateur intégré** : Formulaire d'ajout rapide sur PC qui renomme vos captures d'écran et met à jour le site sans toucher au code.
- 💸 **100% Gratuit & Autonome** : Zéro serveur, zéro base de données payante, propulsé simplement par **GitHub Pages**.

---

### 🚀 Utilisation sur smartphone

1. Ouvrez l'adresse de votre GitHub Pages dans Safari (iOS) ou Chrome (Android).
2. Cliquez sur **Partager** (ou le menu `⋮`) > **Ajouter à l'écran d'accueil**.
3. Lancez l'application en plein écran pendant vos matchs !

---

### 🛠️ Ajouter un nouveau Lineup

1. Ouvrez `index.html` sur votre PC.
2. Cliquez sur le bouton **« + Ajouter »**.
3. Remplissez les informations et sélectionnez vos captures d'écran.
4. Cliquez sur **« Enregistrer & Exporter »** :
   - Téléchargez vos photos déjà renommées et déposez-les dans le dossier `images/`.
   - Téléchargez le nouveau `index.html` et remplacez l'ancien.
5. Poussez les modifications sur GitHub : votre téléphone est automatiquement à jour !
